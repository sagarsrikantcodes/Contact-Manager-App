# Contact Manager

## Overview

Contact Manager is a web application that enables the user to manage their contacts. The contacts can be created, searched, filtered based on tags, edited, or deleted. Tags can be modified from individual contact details. Contacts can be searched based on the search input by the user or based on the filtering the tags by the user. The contacts are sorted alphabetically based on their full names. 

## Files

- `contacts.js` creates `contactManagerApp` object for the entire application involving sending requests to the server and parsing the responses.
- `autocomplete.js` involves creating `search` feature incorporating concepts from the JS230 course.
- `createContact.html` is used for navigating to the new web page while adding new contacts.
- `editContact.html` is used for navigating to the web page for editing or updating the contact details.

## Features 
- Add contact
- Edit contact
- Delete contact
- Search contacts
- Manage tags
- Filter contacts based on tags.

## Client-Side Form Validations for the following parameters
- Full name
- Phone number
- Email
- Tags
